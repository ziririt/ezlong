
# data/knowledge README

이 폴더는 Life Signal 운명 최적화 앱의 클라이언트 실행용 지식베이스다.

중요:

- 혈액형은 사용하지 않는다.
- 원본 생년월일은 저장하지 않는다.
- 모든 결과는 질문 응답 기반으로 개인화한다.
- 운은 예언이 아니라 기회 포착과 실행 상태로 해석한다.
- 사용자의 나이/성별/성향유형은 문체와 맥락 보정값이지 결정론적 판단값이 아니다.

MVP 최소 목표:

- questions 40개 이상
- trigger_rules 60개 이상으로 확장
- leakage_causes 24개 이상
- prescriptions 120개 이상
- seven_day_routines 12세트 이상
