AI 답변 정리

별표·우물 정·인용 꺾쇠·가로줄을 걷고, 이모지와 “요청하신 내용을 정리해 드리겠습니다” 같은 서두를 지웁니다. 깨진 표는 칸을 맞춰 되살립니다.

Markdown 완전 제거

마크다운 문법을 최대한 지웁니다. 표는 탭으로 나뉜 형식(TSV)으로 바꿔 엑셀·구글 시트에 바로 붙게 합니다.

최소 정리

구조는 그대로 두고 잡티만 없앱니다. 눈에 안 보이는 제로폭 문자, 줄 끝 공백, 이상한 공백 문자 같은 것들.

표만 뽑기

글은 버리고 표만 꺼냅니다. 여러 개면 여러 개 다. 곧바로 시트에 붙일 형태로 나옵니다.

블로그 붙여넣기

마커는 지우되 링크 주소는 살립니다. 붙여넣은 뒤 다시 링크를 찾아 헤매지 않도록.

표는 두 가지 방법으로

화면에서는 칸을 맞춰 읽기 좋게, ‘표 복사’ 단추로는 시트에 붙을 형태로. 같은 표를 쓰임새에 따라 다르게 내놓습니다.

글은 여기서 나가지 않습니다.

정리는 전부 이 브라우저 안에서 이루어집니다. 서버로 보내는 것이 없으니 저장할 것도, 볼 사람도 없습니다. 인터넷이 끊겨도 한 번 연 뒤에는 그대로 동작합니다. 회원가입도 로그인도 없습니다. 쓰는 엔진은 앱과 같은 것입니다 — 웹에서 정리한 결과와 앱에서 정리한 결과가 다르지 않습니다.

더 자주 쓰신다면, 앱이 낫습니다.

웹은 한 번 쓰고 닫는 자리입니다. 앱에는 메모가 남고, 되돌릴 수 있고, 버전 기록이 쌓입니다. 배경을 고르고, 표를 눌러 시트로 보내고, 직접 발급한 API 키로 요약·번역까지 맡길 수 있습니다.
