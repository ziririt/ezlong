상태가 바뀐 날과 매매가 나간 날만 표시. 상태 확정은 2-of-3 지속성(하루 지표로 바꾸지 않음), 급락일은 Shock Transition 으로 즉시 전환.

이 화면의 한계

  • 모든 비중·임계치는 백테스트용 초기값: S1 12% · S2 22% · S3 27% 등은 하드코딩 최종값이 아님. walk-forward 검증(Phase 3) 전에는 실거래 판단 근거로 사용 금지.
  • 체결은 당일 종가로 근사: 원칙은 신호 다음 거래일 시가 체결. 상태 판정 검증이 목적인 Phase 1 에서는 오차가 작으나 Phase 3 백테스트에서 정밀화.
  • breadth·수급은 무료 프록시: 동일가중/시총가중 상대 모멘텀과 상승·하락일 거래량 배분으로 근사. CVD·GEX 는 무료 데이터 부재로 기각(기획서 3부).

  • 확률 도구이지 예측 도구가 아님. 성공 기준은 적중률이 아니라 세운 작전의 실행률.
