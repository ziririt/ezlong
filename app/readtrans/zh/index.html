使用方法

书仍在你常用的阅读器里读。ReadTrans 在旁边只负责翻译。

1打开阅读器

在 Kindle、Apple Books 等阅读器中打开要读的书。

2在 ReadTrans 中选择阅读器

在 ReadTrans 中选中那个阅读器窗口。仅第一次需要允许屏幕录制和辅助功能权限。

3翻页即翻译

在 ReadTrans 中翻页，阅读器也会一起翻页，旁边的译文立即更新。

常见问题

我的书会被发送出去吗？

使用默认翻译时不会。识别屏幕文字和翻译都在你的 Mac 上完成，也不保存屏幕图像。会联网的只有授权验证（密钥和设备名称），以及为了让译文贴合本书而查询的书名。只有在你主动开启 AI API 翻译时，当前页的文字才会发送到你选择的 AI 服务商。

AI API 翻译要花多少钱？

费用由你选择的 AI 服务商向你自己的账户收取，而不是 ReadTrans，各家价格差别很大。应用设置里可以看到各服务商的预估费用和目前累计的预估金额。不填 API 密钥、只用本机默认翻译也可以。

支持哪些阅读器？

目前测试完成的是 Mac 上的 Kindle 和 Apple Books。PDF 和图片文件（PDF·PNG·JPEG·TIFF·HEIC）无需阅读器，可直接在 ReadTrans 中打开。

Windows 版什么时候推出？

正在开发中。日期确定后会在本页公布。计划让在 Mac 上购买的授权也能在 Windows 上使用。

可以退款吗？

购买之日起 14 天内发邮件至 support@ezlong.com 申请，不问原因全额退款。支付给 AI 服务商的 API 费用 ReadTrans 无法退还。

可以在多台 Mac 上使用吗？

一个授权最多可激活两台设备。要转移时，在应用设置中选择“在此 Mac 上停用”，再在新设备上激活即可。
