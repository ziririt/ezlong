원문 배치를 닮은 번역 종이

단 나눔, 제목 크기, 각주 번호, 들여쓴 인용문까지 원문 쪽의 모양을 따라 번역을 앉힙니다.

넘기는 즉시

지금 쪽을 읽는 동안 다음 쪽들을 뒤에서 미리 번역해 둡니다. 넘기면 기다림 없이 이어 읽습니다.

기본 번역은 내 Mac 안에서

글자 읽기와 기본 번역을 모두 내 Mac의 번역 모델이 합니다. 책 화면과 문장을 서버로 보내지 않고, 화면 그림도 저장하지 않습니다.

내 AI 키로 더 자연스럽게

9개 회사 중 하나의 내 API 키를 넣으면 더 매끄러운 번역을 씁니다: ChatGPT (OpenAI), Claude (Anthropic), Gemini (Google), Grok (xAI), Mistral, DeepSeek, Qwen (Alibaba), Kimi (Moonshot), GLM (Zhipu Z.ai). 이때만 지금 쪽의 글자가 고른 회사로 갑니다.

내 번역을 배우는 AI프리미엄

번역을 고치면 어떤 낱말을 어떻게 바꿨는지 기억해, 그 책의 다음 쪽부터 내 말투로 맞춥니다.

번역 고쳐 저장·내보내기프리미엄

마음에 들지 않는 문장을 직접 고쳐 저장하고, 읽은 번역을 내보냅니다. 번역한 PDF는 번역을 입힌 새 PDF로 저장합니다.

자주 묻는 질문

내 책이 밖으로 나가나요?

기본 번역을 쓰면 나가지 않습니다. 화면의 글자를 읽는 일과 번역을 모두 내 Mac 안에서 하고, 화면 그림은 저장하지 않습니다. 인터넷으로 나가는 것은 라이선스 확인(키와 기기 이름)과, 번역을 책에 맞추려고 찾는 책 제목 정도입니다. 직접 AI API 번역을 켠 경우에만 지금 쪽의 글자가 고른 AI 회사로 갑니다.

AI API 요금은 얼마나 드나요?

요금은 ReadTrans가 아니라 고른 AI 회사가 내 계정에 매기며, 회사마다 크게 다릅니다. 앱 설정에서 회사별 예상 요금과 지금까지 쓴 예상 금액을 볼 수 있습니다. API 키 없이 기본 번역만 써도 됩니다.

어떤 뷰어에서 되나요?

지금 시험을 마친 것은 Mac의 Kindle과 Apple Books입니다. PDF와 그림 파일(PDF·PNG·JPEG·TIFF·HEIC)은 뷰어 없이 ReadTrans에서 바로 엽니다.

Windows판은 언제 나오나요?

만들고 있습니다. 날짜가 정해지면 이 쪽에 알립니다. Mac에서 산 라이선스로 Windows에서도 쓸 수 있게 할 예정입니다.

환불되나요?

구매일부터 14일 안에 support@ezlong.com 으로 요청하시면 까닭을 묻지 않고 환불합니다. AI 회사에 낸 API 요금은 ReadTrans가 환불할 수 없습니다.

여러 Mac에서 쓸 수 있나요?

라이선스 하나로 기기 두 대까지 활성화합니다. 옮기려면 앱 설정에서 「이 Mac에서 해제」를 누른 뒤 새 기기에서 활성화하면 됩니다.
