## 1. 큰 그림

- insightimes.com 이 독자를 만나는 얼굴, ezlong 은 시장 데이터와 계산 엔진. 독자에게는 하나의 매체로 보인다(ezlong 이름은 독자 화면에 내지 않는다: 인사이트타임스 운영 규칙).
- 통합의 세 켜
  - 데이터 켜: ezlong 이 이미 만드는 JSON(스윙 상태, 시장 체제, 긍정 대 부정, 오늘의 차트, 그날 무슨 일, 시총 100 주가, AI 기술적 분석 50종목)을 기사 안으로 들인다.
  - 화면 켜: ezlong 도구 페이지를 insightimes.com/tools/ 아래에서 그대로 연다(워커가 ezlong.com 원본을 받아 웹진 껍데기를 씌움). 쿠키 · 로그인(크루) · 검색 권위가 한 도메인에 모인다.
  - 사람 켜: 크루(구글 로그인, 활동명)가 도구 결과를 글에 끼우고, 도구는 크루원의 관심 종목을 기억한다.

## 2. ezlong 쪽에 부탁하는 일 (우선순위 차례)

### 2-1. market-context.json 한 장 (가장 먼저, 반나절)

지금은 파일이 여섯 군데라 웹진이 여섯 번 받아야 한다. 한 장으로 모아 달라.

- 경로: `data/market-context.json` (GitHub raw 와 ezlong.com/data/ 둘 다에서 읽힘)
- 갱신: 기존 워크플로(swing-ai · market-scorecard · fetch-today-chart · fetch-market-cycle · weekly-risk)가 끝날 때마다 다시 만든다. 만드는 스크립트 하나(`scripts/build-market-context.py`)를 각 워크플로 끝에 한 줄로 부른다.
- 꼴(v1, 바뀌면 `v` 를 올리고 옛 칸은 한 달 남긴다)

```json
{
  "v": 1,
  "generatedAt": "2026-10-27T05:10:00Z",
  "swing": { "asOf": "2026-10-24", "state": "CORRECTION", "stateKo": "조정", "temp": 3, "symbols": { "QQQ": {"score": 41, "state": "CORRECTION"}, "SOXX": {}, "TSLA": {}, "NVDA": {} } },
  "regime": { "asOf": "2026-10-24", "code": "TECH_LEADING_WARNING", "ko": "반도체 선행 경고", "scores": { "exuberance": 39.6, "fragility": 14.5, "breakdown": 0, "repair": 84.9 } },
  "scorecard": { "at": "2026-10-26T13:25:00Z", "positive": 35, "negative": 65, "summary": "…", "keyEvent": { "name": "FOMC 금리 결정", "time": "10월 28일(수) 14:00 ET", "why": "…" } },
  "weeklyRisk": { "week": "2026-W43", "overall": "…", "axes": { "overheat": 0, "fragility": 0, "breakdown": 0, "repair": 0 } },
  "todayChart": { "at": "2026-10-26T08:25:00+09:00", "symbols": { "TSLA": { "price": 372.22, "chg": -0.63, "rsi14": 46.4, "ema20": 370.9, "ema200": 378.2, "verdict": "…한 줄" } } },
  "prices": { "at": "…", "symbols": { "NVDA": { "p": 0, "chg": 0 } } },
  "links": { "swing": "/swing-ai.html", "scorecard": "/market-scorecard.html", "todayChart": "/today-chart.html", "briefHistory": "/brief-history.html?d=" }

```

- 숫자는 이미 있는 값을 옮겨 담기만 한다. 새 계산 · 새 모델 호출은 없다(비용 0).
- 웹진은 15분마다 `generatedAt` 이 바뀌었을 때만 받아 KV 에 둔다. 하루 100번 안쪽.

### 2-2. 도구 페이지의 '껍데기 바꾸기' 모드 (1세션)

- `?skin=it` (또는 요청 헤더 `X-IT-Skin: 1`)가 오면 ez-nav · ez-footer · 앱 배너 · 광고 자리를 그리지 않고 본문만 그린다. 웹진 워커가 그 둘레에 인사이트타임스 머리 · 꼬리 · 글꼴 · 색을 씌운다.
- 색 · 글꼴은 ez-design.css 의 변수로만 닿게 해 달라(`--ez-bg`, `--ez-ink`, `--ez-accent`, `--ez-font`). 웹진이 변수만 덮어 쓰면 되도록.
- 자산 경로는 절대 경로(`/ez-nav.js`, `/data/…`, `/assets/…`)를 유지해도 된다. 워커가 `/tools/` 아래에서 그대로 되돌려 준다(아래 3-2).
- 먼저 할 페이지 여섯: dca-simulator, compound-calculator, backtest, portfolio-manager, risk-diagnostic, brief-history. 나머지는 뒤에.

### 2-3. 계산기 '끼우기' 모드 (1세션)

- `?embed=1&preset=…` 로 열면 제목 · 설명 · 주변 글 없이 계산기 본체만 그리고, 높이가 바뀔 때 `window.parent.postMessage({ ezEmbed: 'height', h })` 를 보낸다.
- preset 꼴: `dca-simulator?embed=1&sym=TSLA&monthly=300000&years=10`, `compound-calculator?embed=1&principal=…&rate=…&years=…`. 받는 칸 이름을 문서(README 한 절)로 고정해 달라.
- 기사 편집실이 `{{tool:dca sym=TSLA monthly=300000 years=10}}` 한 줄로 끼운다. 계산은 ezlong 이, 글은 웹진이.

### 2-4. 크루 관심 종목 받기 (뒤)

- `/tools/` 아래에서 열리면 같은 도메인이라 크루 로그인 쿠키(itc)가 그대로 간다. 웹진이 `window.IT_ME = { nick, watch: ['TSLA','NVDA'] }` 를 머리에 심어 줄 테니, 도구는 있으면 그 종목을 먼저 보여 주면 된다. 없으면 지금처럼.

### 2-5. 거꾸로: 웹진이 ezlong 에 주는 것

- 기사 목록(`data/insightimes.json`)은 이미 간다. 더해서 날짜별 기사 지도(`search.json` 의 m 칸: 그 미국 장 날짜에 나온 기사)를 `/api/market-days.json` 으로 내보낸다. brief-history 날짜 카드에서 '그날의 기사' 를 바로 붙일 수 있다.
- 크루 글 가운데 공개 글 최신 10편(`/cafe/api/posts?page=0` 손님 응답)을 쓸 수 있다.

## 3. 웹진 쪽이 할 일 (ezlong 쪽은 몰라도 되지만 맞물리는 곳)

- 3-1. `src/market.js`: market-context.json 을 15분마다 받아 KV `ez:ctx` 에, 공개 API `/api/market/context`(엣지 5분 캐시).
- 3-2. `/tools/*` 되돌려 주기: 워커가 `https://ezlong.com/<path>?skin=it` 을 받아 `<body>` 안쪽만 떼어 웹진 껍데기에 넣고 canonical 을 insightimes.com 으로. `/tools/ez-*.js`, `/tools/data/*`, `/tools/assets/*` 도 같은 식으로 되돌린다. 엣지 캐시 10분, HTML 은 1분.
- 3-3. 기사 부품 셋: 시장 온도 띠(시황 · 거시 기사 머리), 종목 카드(종목 칩 → 주가 · RSI · AI 한 줄), 그 뒤 어떻게 됐나 안쪽 그래프(brief-history-chart.json 으로 SVG, 라이브러리 없이).
- 3-4. 편집실 `{{tool:…}}` 블록과 미리보기.
- 3-5. 크루: 글쓰기에 '도구 결과 끼우기'(지금 본 계산기 상태를 preset 으로 저장), 도구 쪽에 '크루에서 이야기하기'.
- 3-6. 아침 편지에 시장 온도 · 이번 주 큰 일정 한 줄.

## 4. 지켜야 할 선

- 독자 화면에 ezlong 이름을 내지 않는다. 도구 묶음 이름은 '투자 도구'(가칭).
- 기사에 들어가는 숫자는 asOf 와 함께 보이고, 단정 어조를 쓰지 않는다(웹진 기사 태도 규칙).
- 아이폰 사파리에서 안 되는 것은 하지 않는다.
- 비용: 새 모델 호출 없음. 워커 요청은 엣지 캐시로 막는다. 월 10만원 선 유지.
- ezlong.com 은 한동안 그대로 산다(앱 · 광고 · 기존 유입). canonical 이동은 insightimes.com/tools/ 유입이 ezlong.com 유입을 넘긴 뒤 성동님이 정한다.
