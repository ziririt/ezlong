# 스윙 개편 설계 노트 (2026-07-30)

## 확정 1 — 캠페인 원장은 내부 전용 (유저 확정)

"캠페인 D+12 · 3/6차 진입 · 평단 671.2" 같은 내부 상태를 사이트에 노출하지 않는다.
원장은 판단의 재료(주방)이고, 공개되는 것은 수석 애널리스트의 논평(요리)뿐이다.

## 확정 2 — 공개 출력의 표준: 능숙한 애널리스트 논평체

방문자는 가끔 와서 "오늘 이 시간이 어떤 스윙 타이밍인지"만 알면 된다. 요구사항:

- 지금이 분할매수 / 보유 / 익절 시작 / 청산 / 관망 중 무엇의 구간인지 하나로 확정해 말한다
- 이미 몇 차례 분할했는지의 맥락이 "문장에 배어" 있어야 하되 장부 수치는 노출하지 않는다
  (예: "이번 조정에서 계획된 분할 매수는 이미 상당 부분 진행됐다")
- 휩쏘/가짜 반등 위험 구간이면 그렇다고 말한다 (Engine B confluenceChecklist 근거)
- 과거 판단이 틀렸으면 스스로 인정한다 — 자기 채점 루프:
  판단원장 + 캠페인 원장의 과거 스탠스 vs 실현 수익률을 매일 자동 대조,
  빗나간 판단은 다음 논평에서 명시적으로 언급 ("지난달 말 반등 때 이틀 속았다")
- 확률 표현 허용 — 단 백테스트 조건부 통계가 있는 경우에만
  (예: "무추세 ADX + 저거래량 반등 조합은 지난 10년 사흘 내 되밀림 빈도 약 6할")
- 뭉뚱그린 책임 회피 금지. 관망일 때도 "왜 오늘은 아무것도 안 하는 게 맞는지"를 근거로 말한다
- UI 말투 원칙(분석/진단형)은 유지하되, 1인칭 자기 평가("저도 속았습니다")는 허용

## 공개 데이터 구조 (chief-view.json 예정)

- stance: accumulate | hold | take_profit | exit | wait  (하나로 확정)
- confidence: 상/중/하 + 근거 요약
- commentary: 애널리스트 논평문 (한국어/영어)
- selfReview: 최근 판단 자기 채점 문장 (틀렸을 때만 생성)
- 내부 원장(swing-campaign-ledger.json 예정)은 별도 파일, UI에서 읽지 않음
