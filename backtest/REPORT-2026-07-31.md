작성: 2026-07-31 새벽 (클라우드 세션, Fable 5) · 사이트 코드 무변경 · 연구 브랜치 feature/swing-backtest

## 1. 결론 요약

- 방문자 이탈의 원인은 모델 성능이 아니라 **무기억 구조**로 실측 확인됨. "1차(30%) 분할 진입" 문구가 8거래일 연속 반복되는 동안 QQQ가 −4.5% 하락 — 내역을 기억했다면 2·3차 추가 진입을 말했어야 할 구간.
- 점수 자체의 엣지는 얇다(인덱스 기준). 검증된 신호는 사실상 두 개: **매도점수 60+ 경고**(이후 20일 수익 급감)와 **200일선 레짐**. 따라서 "언제 사냐"의 마이크로 타이밍보다 **"얼마나 들고 있느냐"의 노출 관리 + 내역 기억**이 정답.
- 최종 제안 구조(v4, 노출 변조 + 캠페인 원장): 아웃오브샘플(2021~2026.7, 파라미터 미조정) 성과 —
  연 12.3% vs 보유 15.3%, **최대낙폭 −20.7% vs −35.6%**, 샤프 0.84 vs 0.74, **2022 약세장 −17.8% vs −33.7%**.
  상승장 수익 일부를 내주고 폭락 방어와 심리적 지속가능성을 사는 구조 — 스윙 사이트의 존재 이유와 정합.
- TSLA·NVDA는 **현행 점수 문법이 역효과**임이 드러남(아래 4절). 별도 설계 필요 — 이번에 적용하지 않고 2차 과제로.
- 사이트 반영 전 **30일 섀도 러닝**(가상 운영, 원장에만 기록) 제안.

## 2. 진단 — 실측 데이터

git 히스토리에서 봇이 커밋한 market-signals.json 스냅샷 2,169개(2026-05-15~07-30, 57거래일)를 복원.

- 문구 밴드 분포: "1차 진입"(65~79점) 22일, "관망"(50~64점) 26일, "자제"(<50점) 9일, "최적"(80+) 0일
- 최장 반복: "1차 진입" **8거래일 연속 × 2회** (6/15~6/24, 6/30~7/7)
- 그 두 구간에서 QQQ는 각각 **−4.5%, −3.7% 하락** — 같은 문구가 반복되는 동안 분할 매수의 실제 기회가격이 지나감
- 반대로 "자제" 7일 연속 구간(5/20~5/26)에서 QQQ +2.4% 상승
- 구조 결함 추가 확인: 스윙시그널 SELL 도트는 sellScore가 아니라 **buyScore의 역매핑** (atmr-dashboard.html 3456행) — BUY/SELL/HOLD 세 칸이 한 점수로 움직여 서로 다른 정보를 못 줌
- 오케스트레이터 부재: 판단 엔진 4개(점수·차트분석·스코어카드·오늘의차트)가 서로의 판단을 읽지 않음.
  같은 날 점수 엔진 "68점 진입" vs 차트 엔진 "관망 5/10, 위장반등 1/5" 모순 실증 (2026-07-30).
  swing-brief.json 배너는 2026-06-26 이후 사망(생산 주체가 repo에 없음), Engine B 체크리스트는 생성만 되고 UI 미표시.

## 3. 방법론 (신뢰성 근거)

- 점수 재계산: 로직 재구현이 아니라 **라이브 스크립트(fetch-market-data.py)의 함수를 그대로 import** 해 12년 일봉에 적용. 2년(504거래일) 윈도우도 라이브와 동일하게 맞춤.
- 재현 검증: 알고리즘 최종 개정(7/9 ADX 팩터) 이후 실기록 15일과 대조 — **10일 오차 0**, 나머지는 장중 스냅샷 vs 종가 차이로 설명. 5/15~7/9 구간의 큰 오차는 당시 알고리즘이 구버전이었기 때문(재현 오류 아님).
- 데이터: GitHub Actions로 수집한 12년 일봉(QQQ·VOO·SOXX·TSLA·NVDA·TQQQ·SOXL·VIX), 샌드박스 외부 API 차단 우회.
- 과적합 방지: 파라미터 조정은 **2015~2020(IS)에서만**, 2021~2026.7(OOS)은 손대지 않고 1회 평가.
- 한계: 슬리피지·세금·배당 미반영, 종가 체결 가정, 표본 1개 시장(미국 대형 기술주 중심), 2020 이전 점수는 현행 함수 소급 적용(당시 실제 서비스와 다름).

## 4. 이벤트 스터디 — 신호별 예측력 실측 (수석 논평의 "확률 근거" 목록)

기간: 2015.6~2026.7, 전체 평균 20일 선행수익 +1.50% (인덱스 종합 기준선).

인덱스 종합 (QQQ4:VOO3:SOXX3)

- buy 밴드별 5일 수익/승률: <50 → +0.04%/56%, 50-64 → +0.37%/58%, 65-79 → +0.50%/64%. 방향은 맞지만 얇음. 80+는 11년간 12일뿐(사실상 발동 안 함 — "최적 구간" 문구가 죽어있던 이유).
- **sell 60-74 경고 유효**: 이후 5일 −0.32%(승률 48%), 60일 +0.08% vs 기준 +5.00%. 이 시스템에서 가장 검증력 있는 신호.
- 65 상향 돌파(이벤트)와 65+ 체류(레벨)의 선행수익 차이는 미미 — 돌파 이벤트의 가치는 수익 예측이 아니라 **행동 규율**(중복 안내 제거)에 있음.
- 휩쏘 가설 기각: ADX<20 + 일간 +1% 반등 이후 5일 승률 62%, 3일 내 마이너스 39%에 불과. "무추세 반등 = 위장" 논평은 인덱스에선 근거 없음 (이 가설은 제가 세웠고, 데이터가 기각했음).

TSLA (역추세 성격)

- buy 50-79 구간 승률 ~50% — 중간 점수대는 사실상 동전던지기. **buy 80+ (n=61): 20일 +15.31%/승률 69%** — 급락 극단에서만 진짜 기회.
- **sell 75+ 이후 20일 +7.50%/승률 65%** — 과열 익절 유도가 역사적으로 상승 지속 구간을 팔게 만듦. 현행 문법의 역효과.
- gear1(하락추세)의 선행수익이 gear3보다 높음 — 평균회귀 종목.

NVDA (추세 지속 성격)

- gear3 20일 +5.87%/승률 69% vs gear1 +2.29%/56% — 추세 추종이 정답.
- sell 신호 전 구간 무의미(과열이 과열로 안 끝남). 기준선 자체가 20일 +5.25% — 현금 드래그가 곧 손실.
- 시사점: TSLA와 NVDA에 같은 점수 문법을 쓰는 현행 구조는 한쪽(또는 양쪽)에서 틀릴 수밖에 없음. 종목 성격별 문법 분리가 2차 과제.

## 5. 알고리즘 실험 경과 (실패 포함 전부 기록)

- v1 순수 캠페인(이벤트 진입 + 전량 분배): MaxDD −5~−13%로 방어는 최강이나 노출 부족으로 OOS 연 4.3% — 탈락.
- v2 러너 구조(익절해도 40% 유지 — "1차 익절 후 꺾일 때까지 고공행진"): 개선 미미 — 진입 트랜치가 안 채워지는 게 병목.
- v3 추세 증액(신호 유지 N일 시 증액 = 3-3-4 원칙의 "2차·3차") + 200일선 회복 재진입: 노출 70→75%, IS 연 11% — 방향은 맞으나 손절-재진입 휩쏘 비용 큼.
- **v4 노출 변조(최종 제안)**: 매일 목표 노출을 정하고(기어3=100%, 기어2=60%, 기어1=0~20%, sell 60+ 경고 시 60%로 축소, 75+ 시 35%, 200일선 −5% 2연속 시 0%), 실제 노출은 트랜치(최대 20%p, 쿨다운 2일) 단위로만 접근. 트랜치 이동 자체가 원장 기록이 됨.
- v4 강건성: IS에서 파라미터 9종 변형 모두 연 14.2~14.9%/DD −21~−23% 범위 — 특정 값에 과적합돼 있지 않음.

성과 비교 (모두 같은 데이터, 같은 기간)

- IS(2015.6~2020.12): v4 연 14.5% / DD −22.4% / 샤프 0.94 / 평균노출 81% ← 보유: 연 21.2% / DD −28.6% / 샤프 0.99
- OOS(2021.1~2026.7): v4 연 12.3% / DD −20.7% / 샤프 0.84 / 액션 159회(월 2.4회) ← 보유: 연 15.3% / DD −35.6% / 샤프 0.74
- 연도별(OOS): 2021 +28.0 vs +28.6 · **2022 −17.8 vs −33.7** · 2023 +32.3 vs +54.8 · 2024 +19.4 vs +27.0 · 2025 +11.5 vs +20.4 · 2026(7월까지) +4.2 vs +11.2
- 읽는 법: 약세장 방어(2022)와 회복 속도(2023 초 저점에서 앞서 있음)를 사고, 강세장 최상단 참여를 일부 내준다. 샤프(위험 대비 수익)는 v4 우위. 월 2~3회 액션 = 분할 5~10회 요구와 정합.

## 6. 공개 출력 설계 (확정 반영)

- 원장(몇 차, 평단, 노출률)은 **내부 전용**. 공개는 스탠스 1개 + 애널리스트 논평문.
- 스탠스: 분할매수 유리 / 보유 / 익절 시작 / 축소·청산 검토 / 관망 — 매일 하나로 확정.
- 논평 예시 (v4 상태 + 검증 통계로 자동 생성될 문장의 표준):
  "지금은 새로 살 자리가 아니라 버틸 자리입니다. 이번 조정에서 계획된 분할 매수는 이미 상당 부분 진행됐고, 오늘 가격은 마지막 매수 구간에서 1%도 안 떨어져 있어 여기서 더 사는 건 분할이 아니라 추격입니다. 다만 매도 압력 점수가 60선을 넘어선 점은 가볍게 볼 수 없습니다 — 이 신호 뒤 20일 수익률은 지난 11년 평균의 3분의 1 수준까지 떨어졌던 이력이 있습니다. 솔직히 지난달 말 반등 때는 이틀 연속 진입 쪽에 섰다가 3% 넘게 되밀리는 걸 그대로 맞았습니다. 그때와 지금의 차이는 주봉 추세가 아직 살아있다는 것 하나이고, 그래서 보유분 손절은 이르다고 봅니다."
- 자기 채점 루프: 판단원장 스탠스 vs 실현 수익률을 매일 대조, 빗나감은 다음 논평에서 명시 인정.
- 확률 표현은 4절의 검증 통계가 있는 경우에만 허용. 통계 없는 확률 문장 금지.

## 7. 적용 로드맵 (전부 성동님 승인 후 착수)

1. 섀도 러닝 30일: 파이프라인에 원장 파일(비공개)과 chief 논평 생성만 추가, UI 무변경. 매일의 스탠스가 실제로 어떻게 나오는지 관찰.
2. 스윙시그널 코너 교체: 무기억 문구 → 스탠스 + 논평. SELL 도트를 진짜 sellScore 기반으로 교정.
3. 수석 레이어(chief-view.json): 4개 엔진 모순 조정 + 공통 컨텍스트 스트립. 죽은 swing-brief 배너 대체.
4. TSLA·NVDA 문법 분리 설계(2차 백테스트): TSLA=극단 과매도 분할 + 변동성 스톱, NVDA=추세 유지 중심.
5. Engine B 체크리스트 UI 노출 여부 재검토 — 인덱스에선 예측력 근거 약함(4절), 레버리지 페이지 한정 재검증 후 결정.
